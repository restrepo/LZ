# Default design system

- Warm paper (`--color-bg`), near-black ink; 2 px rules instead of shadows.
- Discreet corners (`--radius-md` = 6 px).
- Blue accent (`--color-accent`): results, active controls and the field of the section posters.
- Role accents: green (`--color-accent-3`) for case 1 and amber (`--color-accent-2`) for case 2. Never decorative.
- Headings Archivo 800; body Archivo 400; maths and figure labels in STIX Two Text.
- Avoid: gradients, shadows on cards, more than one accent field per slide.
