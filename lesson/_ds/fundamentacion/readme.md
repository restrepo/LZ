# Fundamentación — sistema de diseño

- Papel cálido (`--color-bg`), tinta casi negra; filetes de 2 px en lugar de sombras.
- Esquinas discretas (`--radius-md` = 6 px).
- Acento azul (`--color-accent`): resultados, controles activos y el campo de los pósteres de sección.
- Acentos de rol: verde (`--color-accent-3`) para la cantidad de movimiento/caso 1,
  ámbar (`--color-accent-2`) para la solución analítica/caso 2. Nunca decorativos.
- Encabezados Archivo 800; cuerpo Archivo 400; matemáticas y rótulos de figuras en STIX Two Text.
- Prohibido: degradados, sombras en tarjetas, más de un campo de acento por diapositiva.
